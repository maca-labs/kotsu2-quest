## 修正方針と範囲

全36依頼・818工程をポイント、暗号資産/資金準備/追加講座、共通の物語とUIへ分けて確認した。初回レビュー3担当、編集3担当、独立再レビュー3担当、別環境での画面確認担当へ分担。子の同時稼働は最大3。

| 以前の問題 | 修正例 |
| --- | --- |
| 「登録メールを送信を押す」など、助詞とボタン名が曖昧 | 短いボタン名と、そのボタンを押す指示を分けた |
| 「チップを押す」だけで入力先が不明 | 欄の名前と入力する練習値を明記。入力後は実送信ボタン名を矢印に表示 |
| `occupation=employee`など、開発用の表現が結果に表示 | 「職業が『会社員』に設定される」など、対象と変化が分かる文へ変更 |
| 日付の説明は「1990年4月12日」だが、実入力はISO形式 | 「1990-04-12」（1990年4月12日）と、受理される形式を明示 |
| 貼付先がメール内か登録画面内か不明 | コピー元、戻るアプリ、入力先をサービス名・欄名で区別 |
| 「名義と入金先が同じ」と、異なる種類のものを比較 | 振込人名義は申込者、送金先は受取カードとそれぞれ比較 |
| 申請だけで受取済みに読める | 入力・申請・処理中・予定・実受取を分けた |
| 帰還ボタンで報告まで完了するように読める | 町への移動と、依頼人に結果を知らせる操作を区別 |

暗号資産と資金準備の結果文も、操作名の複写から述語のある文へ改稿した。用語説明の年率、元本と利息、評価額、レバレッジには数量・単位を伴う教材例を示す。
