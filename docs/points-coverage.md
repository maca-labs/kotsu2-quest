# 序章・ポイ活編の工程対応

教材基準日：2026-10-22。`js/content-points.js` は添付 pointquest 詳細仕様の操作行を、安定した工程 ID のまま収録しています。表の工程数に NPC 会話・受注・町の移動・章ボスを含めません。

|章|クエスト|標準工程数|
|---|---|---:|
|序章|PR-01|12|
|第1章|PO-01 / PO-02 / PO-03 / PO-04 / PO-05 / PO-06|19 / 13 / 13 / 10 / 12 / 10|
|第2章|BK-01 / BK-02 / TR-01|32 / 23 / 26|
|第3章|FX-01 / FX-02 / FX-03|18 / 20 / 12|
|第4章|TC-01 / TC-02|21 / 32|
|合計|通常15クエスト|273|

PO-01〜06 の標準 ID は仕様どおり P001〜P077 です。追加課題 BK-02-R（6工程）と FX-02-S（18工程）は親クエストと別 snapshot です。追加課題のクエスト報酬・時限報酬は 0、工程初回報酬だけを対象とします。全登録工程は297、重複 ID はありません。

各操作行の元の画面名、操作文、成立結果を `rawRows` に残し、実際の入力欄・候補・チェック・選択を `O` に定義しています。金融元帳は finance.js が担当し、content-points.js の効果はゲーム内メール、コピー、フォーム、画面、控えだけを更新します。外部クリップボード、カメラ、NFC、実メールへ接続しません。

`guidedMaps` は6分野の各技能と実工程を対応させます。`bosses` の独立した固定条件は章ごと5課題で、金額・口座番号・通貨ペア・費用等を通常練習から変えています。課題の初期値は誤りを直せる値で、`objectiveEvidence` が本人の操作で証明した技能を指定します。第2章では銀行と振込の技能を同じ5課題の中で分けて記録します。

通販案件A/B/C、交換先A/B/C、カートの比較値、架空成人カードは、それぞれ `comparisonPanels` と `practiceProfile` に定義しています。別条件の比較中に、固定金額の元帳を確定しないため、確定直前の金融検証と合わせて使用します。

Node による初回統合確認では、通常15クエストと追加2課題の全297工程、および第1〜4章の全20ボス課題を engine.dispatch で通しました。確認結果は以下のとおりです。
