# 第6章・HYPEステーキングと帰還

## 修正前の公開画面

小6でスマホ操作が苦手な初心者役のAIが、Chromeの360×780で第5章の選択から進めた。最初の残高を確認する画面では、チェック欄のすぐ上にまだ起きていない報酬・値下がり・売却の説明が並び、今どこに10枚あるのかを見るには上に戻る必要があった。

スマホQAが320×360と320×650で再現した。高さ360pxでは委任解除・現物に戻す申請・到着確認のボタンと残高を一緒に読めなかった。数量を「11」と間違えたとき、訂正文は画面の上端から476pxの位置にあった。正しい全角の「１０」も、再読込後に送信すると拒否された。

## ボタンを押すとどう変わるか

この表のHYPE、Mock USDC、日数はすべて練習用。ソラと使うラボは現物10枚、使えるUSDCは0から始まる。

| 操作を終えたとき | HYPEの置き場所と枚数 | できること |
| --- | --- | --- |
| 0日目、現物から移す | ステーキングの手元に10枚 | 委任する相手を選べる |
| 0日目、委任する | 選んだ相手に10枚を委任中 | 1日目から解除できる |
| 1日進める | 委任中10.1枚。1回だけの教材報酬0.1枚を含む | 全部の委任を解除できる |
| 価格を80に変える | 委任中10.1枚。値打ちは808、使えるUSDCは0 | 最初の値打ち1,000との差は192 |
| 1日目、委任を解除する | ステーキングの手元に10.1枚 | 現物へ戻す申請ができる |
| 1日目、現物へ戻す申請をする | 現物へ移動中の10.1枚 | ここから7日を数える |
| 8日目、現物に届く | 現物に10.1枚。使えるUSDCは0 | コインを売れる |
| 全部売る | HYPEは0枚 | 10.1枚 × 80 ＝ 808 USDCを使える |
| ルカと出金する | ハイリキ0、処理中807、財布0 | 教材費1を引いた807の到着を待つ |
| 到着明細を開く | ハイリキ0、処理中0、ラボの受取財布807 | 受取明細を持ってルカへ報告できる |

第5章の旅の財布900 USDC・ガス用0.0009 ETHとハイリキの99 USDC、ほかのラボの受講記録は別に管理している。章ボスでも専用の1 HYPEを使い、80で売って費用1を引いた79を受け取る。

## 検算

金融担当は本編40工程、出金26工程、章ボス5課題37操作、任意の5枚練習5課題30操作を、同じゲーム処理で検算した。15か所の保存復帰、131件の済んだ操作の再送、30件の誤入力で、日数・残高・経験値が二重に増えないことを確認した。委任の解除は1日経過の前後1ミリ秒で検査し、帰りの7日を進めても、到着を処理するまでは売れないことを確認した。

## 短い画面での公開確認

修正版を配信したGitHub Pagesで、Windows版Chrome 157のタッチ画面を320×360と320×650に設定した。技術QAは各サイズで本編40工程と出金26工程をそれぞれ正規の開始セーブから進めた。158画面で次の操作対象の見切れ、通知によるボタンの隠れ、横へのはみ出し、ブラウザー例外は0件だった。全469件の自動テストも合格した。[配信記録](https://github.com/maca-labs/kotsu2-quest/actions/runs/45007934589)

高さ360pxの数量入力では、残高・入力欄・確定ボタンが同時に見えた。間違った「11」を入れると、訂正の言葉が欄の上に出た。全角の「１０」は再読込してから確定できた。2つの画面サイズで別々の委任先を選んで保存し、候補の条件が選択した相手に合うことも確認した。解除数量を元の10枚だけにすると、報酬を含む10.1枚へ選び直せた。[数量欄を再開した画面](./stake-verification/quantity-resumed.png)

委任した直後、解除した直後、帰りの申請をした直後を並べると、1日待つ場面と7日待つ場面の差を読み取れる。報酬・待機・到着の各画面は保存復帰後の台帳とも一致した。[委任中の10枚](./stake-verification/delegated.png) ／ [解除後の10.1枚](./stake-verification/undelegated.png) ／ [帰りの7日間](./stake-verification/in-transit.png)

## 第5章の選択から、ソラとルカへの報告まで

初心者役は公開版の第5章を最初からプレイし、「委任の塔」を自分で予約した。第5章クリア時に設定画面から書き出した未編集のJSONを、新しいChromeの通常の読込画面から開いた。第6章の依頼はまだ0件だった。[第5章で選んだ道](./stake-verification/chapter-five.png)

360×780の画面で、ソラの依頼を受けて天空城の南門から帰り帆の洞窟へ歩き、戦闘を経て練習スマホを開いた。ゲーム内0日目に委任し、1日目に解除すると、報酬込み10.1枚はステーキングの手元にあった。そこから現物への帰りを申請し、8日目に現物へ届いた。売却後は自分で洞窟を出て学者の家へ帰り、ソラと代金808を照合した。[ソラに届けた売却明細](./stake-verification/sora.png)

同じプレイでルカから次の依頼を受けて洞窟へ向かった。ラボの出金26工程を終え、財布への着金とハイリキ残高0を見て、徒歩でルカに報告した。章ボスは別の1枚で受取79を照合し、「暁の冠」を入手・装着できた。ゲームから書き出した完了セーブでも、両方の徒歩帰還・報告、財布807、章印、他の3ラボが未受講のままであることを照合した。[ルカに届けた受取明細](./stake-verification/luka.png)

## 到着した後の言葉

最初の一周では現物の明細を開くと「8日目に到着」と「7日待ちます」が同時に出た。到着後の明細を過去形に直した。最終版の320×360・320×650で、待機中は「あと7日」、到着後は「7日たち、8日目に現物へ届きました」と読めた。保存復帰を含む対象12画面で、残高と次に押すボタンを同時に確認した。[現物に届いた画面](./stake-verification/arrived.png) ／ [修正版の配信記録](https://github.com/maca-labs/kotsu2-quest/actions/runs/45008563384)

最後に初心者役が、第5章で自分で作った未編集のセーブから最終公開版をもう一度プレイした。360×780で受注・洞窟の戦闘・本編40工程・ソラへの徒歩報告・出金26工程・ルカへの徒歩報告まで進み、到着後は待機中0、現物10.1枚と読み取れた。最終ビルドでも自動テストは469件すべて合格。[帰り帆の洞窟での戦闘](./stake-verification/cave-battle.png) ／ [ルカとの照合](./stake-verification/luka.png)
