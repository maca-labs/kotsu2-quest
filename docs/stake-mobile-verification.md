## 修正前の公開画面

小6でスマホ操作が苦手な初心者役のAIが、Chromeの360×780で第5章の選択から進めた。最初の残高を確認する画面では、チェック欄のすぐ上にまだ起きていない報酬・値下がり・売却の説明が並び、今どこに10枚あるのかを見るには上に戻る必要があった。

スマホQAが320×360と320×650で再現した。高さ360pxでは委任解除・現物に戻す申請・到着確認のボタンと残高を一緒に読めなかった。数量を「11」と間違えたとき、訂正文は画面の上端から476pxの位置にあった。正しい全角の「１０」も、再読込後に送信すると拒否された。

## ボタンを押すとどう変わるか

この表のHYPE、Mock USDC、日数はすべて練習用。ソラと使うラボは現物10枚、使えるUSDCは0から始まる。

| 操作を終えたとき | HYPEの置き場所と枚数 | できること |
| --- | --- | --- |
| 0日目、現物から移す | ステーキングの手元に10枚 | 委任する相手を選べる |
| 0日目、委任する | 選んだ相手に10枚を委任中 | 1日目から解除できる |
| 1日進める | 委任中10.1枚。1回だけの教材報酬0.1枚を含む | 全部の委任を解除できる |
| 価格を80に変える | 委任中10.1枚。値打ちは808、使えるUSDCは0 | 最初の値打ち1,000との差は192 |
| 1日目、委任を解除する | ステーキングの手元に10.1枚 | 現物へ戻す申請ができる |
| 1日目、現物へ戻す申請をする | 現物へ移動中の10.1枚 | ここから7日を数える |
| 8日目、現物に届く | 現物に10.1枚。使えるUSDCは0 | コインを売れる |
| 全部売る | HYPEは0枚 | 10.1枚 × 80 ＝ 808 USDCを使える |
| ルカと出金する | ハイリキ0、処理中807、財布0 | 教材費1を引いた807の到着を待つ |
| 到着明細を開く | ハイリキ0、処理中0、ラボの受取財布807 | 受取明細を持ってルカへ報告できる |

第5章の旅の財布900 USDC・ガス用0.0009 ETHとハイリキの99 USDC、ほかのラボの受講記録は別に管理している。章ボスでも専用の1 HYPEを使い、80で売って費用1を引いた79を受け取る。

## 検算

金融担当は本編40工程、出金26工程、章ボス5課題37操作、任意の5枚練習5課題30操作を、同じゲーム処理で検算した。15か所の保存復帰、131件の済んだ操作の再送、30件の誤入力で、日数・残高・経験値が二重に増えないことを確認した。委任の解除は1日経過の前後1ミリ秒で検査し、帰りの7日を進めても、到着を処理するまでは売れないことを確認した。
