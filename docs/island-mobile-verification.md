# 第5章「鍵の群島」のスマホ確認

初心者役は幅360px・高さ780pxのChromeで公開版のタイトルから第5章を選び、セーブの読込みや解答表を使わずに画面の指示をたどった。スマホQAは別のブラウザーで通常のJSON読込みから操作を再現した。実際の児童による観察とスマホ実機での確認は未実施。

## どこで迷ったか

| 公開版で再現した場面 | 修正後に見る場所 |
| --- | --- |
| 灯台守の家で、依頼の前後でセナの肩書きが変わる | 町の会話と依頼カードの両方で「船便係セナ」と表示する |
| みち道・財布の宛先・ハイリキへの道を間違えると矢印が確定ボタンに残る | 訂正の文と矢印が選択欄に戻る。選び直すと確定ボタンに移る |
| 「１２０，０００」を入力して再開すると金額を確定できない | 下書きの表記を保存し、確定時に120,000円として照合する |
| 資産の地図を開く工程で、序章の合言葉を案内する | ホームで「資産の地図（メモ）」を開き、銀行・財布・ハイリキを区別する |
| ハイリキへ送る場面でもルカが自分の財布の宛先を案内する | ハイリキの受取カードから今回の宛先をコピーして、送信元の財布に貼り付ける |
| 資金が到着しても操作のそばには「届く予定」が残る | 最新の残高を出し、短い画面でも固定ヘッダーの下に残高と操作ボタンを収める |
| 章ボスの確認3で指示が重なり、確定ボタンの文字が画面の下で切れる | 課題の条件と操作の指示を1回ずつ表示する。候補を選んだら「選んだ内容で決定」を画面内に表示する |

## 教材の資金の動き

| 操作 | 終わった直後に帳簿で確認すること |
| --- | --- |
| あかつき取引所で申込・本人確認 | 審査結果は「利用可能」。次のこみち交換所は別の教材窓口 |
| 練習銀行からこみち交換所に120,000円を送る | 銀行は80,000円。到着後は交換所で120,000円を使える |
| 104,000円でミチコインを104枚買い、自分の財布に送る | 交換所に16,000円。みち道（MichiNet）の `DEMO-WALLET-A` に費用1枚を引いた103枚が届く |
| 財布の中で種類を替え、次に道を替える | 103枚を1,030 Mock USDCに交換。同じ財布のArbitrumへ移し、費用20を引いて1,010 Mock USDC |
| 道を使うためのガスを用意する | 10 Mock USDCを使い、財布に1,000 Mock USDCと0.001 Mock ETH。引継ぎや接続で残高を増やさない |
| ハイリキへ送る | 受取カードはUSDC・Arbitrum・`DEMO-VAULT-A`。100を送って費用1、ガス0.0001 ETH。財布は900 USDC・0.0009 ETH。到着前は99 USDCが処理中でハイリキの利用可能額は0 |
| 練習時間を進め、受取明細を開く | 処理中は0。ハイリキで使える残高は99 USDC |

独立した会計検証ではFIの70工程とCRの93工程を通し、16の節目で二重操作と保存・再開を確認した。スマホQAでは320×650と320×360で誤選択・誤入力からの訂正、再開、送信と着金を実際のボタンで確認した。

## 一周で確かめたこと

修正前の初心者役は、新規の旅でセナの申込とスイの本人確認を含めて9件・219工程を終えた。各回、町から街道へ出て洞窟の門番と戦い、クリア画面の近道で依頼人に報告した。最後は「今回は運用しない」を選んだ。「鍵守りの石像」の試練では、本編で使った宛先Aから試練の受取カードの宛先Bに直し、別に用意した50 USDCから49 USDCが届いたことを明細で照合した。5つの確認を終え、宝箱から「帰還のランタン」を受け取って装備した。

修正版は[GitHub Pagesのデプロイ](https://github.com/maca-labs/kotsu2-quest/actions/runs/44973354974)が成功し、配信されたHTML・CSS・JavaScriptの変更対象13ファイルとコミット `c2ec2f0` の内容が一致した。公開版で異なる2つの高さを再試行した結果、誤った通貨・道・宛先を選び直せた。320×360では固定ヘッダーの下端が59px、残高表示の上端が68px。送信前・処理中・着金の3画面で次のボタンの下端は276px・298px・318pxに収まった。技術QAの6セッションでJavaScriptの例外と横スクロールのはみ出しは0件だった。

直前の公開版で作った8件のセーブを修正版で開き、コピー・貼り付け・送信待ち・着金の続きに進めた。読み込んだ時点の残高・経験値・完了工程は元のセーブと一致した。自動テスト449件が合格した。

修正後の技術再走は新規セーブで行った。推奨順の9件・219工程を終え、1件目は徒歩、残り8件は近道で報告した。「鍵守りの石像」の5つの確認を通り、宝箱からランタンを受け取って装備した。見送りを選んだあと、運用ラボと取引所の追加課題は未受講だった。

修正後のもう一人の初心者役も新規セーブで始めた。移動と画面操作のヘルパーを使い、教材の答えはその場の画面から判断した。1件目の口座申込と、8件目のハイリキへの入金では、洞窟から歩いて帰る方を選んだ。洞窟の出口から街道へ出て、世界地図の矢印と町の歩数案内をたどり、灯台守の家に入ってセナとルカにそれぞれ報告できた。9件の報告後、独立した章ボスの確認5問を終え、ランタンの装備まで到達した。その途中で見つかった確認3の見出しと決定ボタンを最後に改修した。

[送信後の「処理中99」を見る（320×360）](./island-verification/pending-320.png) ／ [着金と次のボタンを見る（320×360）](./island-verification/arrived-320.png) ／ [徒歩で帰還し、ルカに報告した画面を見る（360×780）](./island-verification/report-360.png)

最後の章ボス改修では、確認3の途中セーブをゲームのJSON読込みから開いた。USDC、Arbitrum、宛先Bを選ぶ3回とも「選んだ内容で決定」を押せた。ローカル版と[最終公開版 `02672ca`](https://github.com/maca-labs/kotsu2-quest/actions/runs/44974674418)で、ボタンの上端と下端は320×360で272〜317px、360×780で673〜718pxだった。両方の幅で確認5まで進み、セナの宝箱でランタンを受け取り、装備一覧の「装備中」まで確認した。
