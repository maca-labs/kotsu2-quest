# 第6章「現物ラボ」の売買と帰還

## 出発条件と公開版の初回観察

公開版を操作して書き出した第5章の記録411操作を、同じ順序でゲームエンジンに通した。最後のラボ選択だけを「現物」に替え、通常のセーブ読込みで第5章の町から再開した。第6章は未開始。第5章で使った練習財布には900 USDCとガス用0.0009 ETH、ハイリキには99 USDCがある。以下の金額はすべてゲーム内の教材値。

小6でスマホ操作が苦手な人を想定したAIが、Chromeの360×780でソラの依頼を受け、野道と洞窟の門番を突破。現物41工程を終えて町でソラに報告し、同じ学者の家で灯台守ルカの依頼を受けた。出金26工程の後は洞窟の出口、野道、町を歩いてルカに受取明細を届けた。流動の古龍の確認5題も終え、暁の冠を受け取って装備した。

- 購入前のボタンのそばに、後で値下がりしたときの評価180が表示されていた。購入直後の2枚と残り800を読むには上へ戻る必要があった。
- 指値では注文状態が英語のままで、別口座で持っていた2枚の資料も表示されていた。小練習を開く前や戻る前に、表示する口座が先に切り替わっていた。
- 幅320pxでは数量や注文を間違えたとき、訂正する欄が画面外に隠れた。初回の道中で宿に戻った際には、町で再開しても完了ボタンに「洞窟から歩いて帰る」と表示された。

## 修正した操作

実際に使える額と持っている枚数を操作のそばに並べた。注文前は予定、購入後は保有明細、売却後は取引明細を表示する。指値を選ぶと、元の口座と小練習に別のお金があること、まだ買えていない枚数、注文用に予約した額が分かる。価格や枚数を間違えたら、矢印が訂正する欄へ戻る。数値欄で受け付けた「2.0」「95.0」を、途中で読み込み直してもそのまま確定できるようにした。スマホ幅で操作中の反応はソラの吹き出しと戦闘画面に出し、直前の反応が次のボタンに重ならないようにした。歩いて報告するボタンは、洞窟と宿で復帰した町で案内を切り替える。
