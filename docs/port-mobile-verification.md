# 通貨の港をスマホ幅で一周する

2026年11月21日。公開版の第3章を、スマホの操作に不慣れな小学6年生を想定したAI担当が遊んだ。画面幅は360px、高さは780px。新しい旅から始め、攻略手順や途中セーブを渡さず、画面に出た案内、十字キー、練習スマホを使った。

## 初見で通った道

| 場面 | 画面で行ったこと |
| --- | --- |
| 通貨の港 | 章を選び、船長の家へ歩いた。ナギから話を聞き、1,000通貨・300ポイントの条件を手帳に控えて受注した。 |
| ふた風の海洞 | 南門から街道へ出て敵と戦い、洞窟の奥の門番を倒した。洞窟では3体の似た絵から奥の敵を推測した。 |
| ナギの最初の依頼・18工程 | ホームで「FX」を押し、通貨ペアと売り買いの値段を確認した。0.1を手入力して「このlot数で進む」を押し、100ドルの内訳を確認。次に1を入力し、1,000ドルと見比べた。注文前の確認まで進めて港で報告した。 |
| ナギの次の依頼・20工程 | 練習用の買い注文を確定し、一覧から自分の取引を選んだ。決済欄に1を入力し、確認画面を経て決済。履歴と損益を保存し、ナギへ報告した。 |
| 港番ウミの依頼・12工程 | ホームの「ポイント」を押し、新規1,000通貨・決済後の残り0・確定損益−120円の記録を添付した。ゲーム内の時間を進めて300ポイントの承認を確認し、ウミに報告した。 |
| 章の最後 | 条件を変えた5問を終え、宝箱から「潮読みの羅針盤」を受け取って港へ戻った。任意の売り練習18工程は未受講。 |

初見担当は帰還にゲーム内の近道も使った。自動テストでは徒歩の帰路も検査した。実際の小学生による理解度・面白さの評価、スマホ実機や実機の日本語キーボードでの操作は未確認。

## 見つかった問題と再現結果

- 「話す」が2か所あり、入り口で十字キー中央を押すと相手が遠かった。室内上部の近道には「ここで話す」と表示する。
- 洞窟の初戦では、画面上の説明と地図上の「門番」の札を結び付けた。街道では現在地から通れる一歩を案内する。港の南門から海洞まで8歩。帰りは左から始めて10歩で港へ着く。
- 2つ目の依頼で、買い注文を出す前からナギが「買って始めた取引」と話していた。ナギの台詞と練習前の説明を「注文を確定する」「一覧に取引が出る」「その取引を閉じる」の順に合わせた。
- 320px幅の技術検証で、数量の誤りを知らせる文が画面外に出ることと、正しい全角入力「０．１」が拒まれることを再現した。訂正後は送信ボタンへ、誤りを確かめた直後は入力欄へ矢印が移る。間違えた時点で工程やXPは進まない。別アプリに移ると警告が消え、元のアプリに戻ると下書きが残る。
- 最初の2件を報告した後、同じ家にすでにいるのに「船長の家へ」と案内された。次の依頼人の名前を出し、室内に戻った場合もその人に話せるようにした。報告や次の話を聞くだけで受注されることはない。

## 確認環境

Chromeのスマホ表示で初見の一周と、途中セーブを使った技術検証を別々に実施した。技術検証では幅320px・高さ650pxと360pxで、FX・ポイントのアイコン、数量エラーからの復帰、全角入力、再読込み後の下書き、明示確定を調べた。ローカル配信はリポジトリ名を含むURLで確認した。
