## 町・室内・洞窟の入口

- 町の既存扉: 依頼人(5,5)、酒場(19,5)、長老(5,15)を維持。
- 新武器防具店: 扉(12,5)、建物x10..14/y2..5。親の町歩行は扉以外を壁として扱う。教材の武具報酬や購入状態は描画側で確定しない。
- 新南出口: (12,17)。既存moveの境界木判定より前に親が出口を検出する。
- 町/洞窟へ入る位置: (12,16)、上向き。洞窟出口は(12,17)。室内は既存roomSpawn/roomExitを継続する。
- 世界への戻り位置: その町/洞窟入口の1タイル南、下向き。戻った直後の再入場を防ぐ。
- 入口へ歩く操作と「近くで話す/調べる」に同じfeatureを使う。親は近道ボタンと章選択も残す。
- マップ切替で既存world-controls.destroyを呼び、長押しを次の地図へ持ち越さない。

## API / 更新口の分離

```js
getRpgMap(mapId) // world / cave:CH-0..6 → 凍結した地図。町・未知IDはnull
getRpgSpawn(mapId, fromMapId?) // {mapId,x,y,direction,walkFrame}。town:CH-nも受理
getRpgCamera(location) // {x,y,width:25,height:18}
stepRpgMap(location, dx, dy) // {location,moved,feature?,transition?:{mapId}}
nearbyRpgFeature(location) // 同じタイルか上下左右1歩以内のfeature。なければnull
renderRpgMap(canvas, state, location) // 純粋描画、使ったcameraを返す
drawTownTravelFeatures(canvas, state) // 既存の町へ店と出口を上描き
townTravelFeatures // shop / world-exitの不変座標
```

親の永続 `rpg.location` は `{mapId}` のみ。タイル位置は `ui.expeditionPosition` に置き、moduleへ渡す時にmapIdと合わせる。moduleはstate、受注、進捗、コイン、勝利、装備、保存を更新しない。

世界featuresのtypeはtown/caveで、chapterId/targetMapIdを持つ。activeQuestKeyの受注が未完了なら、その章の洞窟に金色の枠と旗を静止表示する。初期状態や達成済みの受注に目的地の完了を装う印は付けず、町の自由な選択は維持する。洞窟の3か所(6,8)/(18,8)/(12,4)にはtype:`quest-gate`とchapterIdを置く。接触はfeatureを返すだけで、実際の敵IDや勝利を作らない。親がengine.getAvailableEncountersから入口/進捗遭遇を選び、未倒/勝利/復帰recordKeyを処理する。quest-gateは通行可能な床であり、利用可能な敵がなくても出口や他章を塞がない。

購入武具の見た目は、既存equippedItemsへ `rpg.equipped.weapon` をweapon、armorをshieldとしてshadowした値をdrawPersonへ渡す。教材装備の原データは変更しない。攻防の数値はengine所有。既存drawPersonで武器の形を区別する拡張は親のworld.js担当とする。

## カメラ・スマホ幅

世界の64×48全体を縮小せず、現在地を追う25×18タイルを400×288論理pxへ描く。端ではカメラを0..39/0..30に固定。洞窟25×18は全体が入る。瞬間的な1タイル移動で、強制アニメーションを追加しない。

タップ座標は同じcameraから `camera.x + (clientX-left)*25/width`、`camera.y + (clientY-top)*18/height` を求める。地図の内部スクロールは作らず、ページの標準スクロールと既存64px十字キーを維持。専用CSSは画像の比率・折返し・行動ボタン48px以上、420px以下の縦並びを用意する。現在地名・目的地名の普通の文字は親UIがcanvas外へ置く。
