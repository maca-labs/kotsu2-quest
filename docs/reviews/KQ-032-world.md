# KQ-032 — 追加講座の世界・村人・長老・用語

結論：国内口座・売買・貸出・選べる先物の7講座に、固有の困りごと、敵、確認に応じた封印、町の変化と無料の相談を追加した。共通state、台帳、XP、章印、装備条件は変更していない。これは実装・自動検証の報告であり、人間の面白さ・学習理解の実証ではない。

担当：world_engineer / 2026-10-23 JST。単一所有の製品編集は `js/adventure.js`、`js/help.js`、`js/ui-adventure.js`、`js/world.js`、`styles/world-extension.css` と担当3テストのみ。孫エージェントなし。

読了：適用されるルートAGENTS、agents/world_engineer、PRODUCTION、CONTRACTS EXT1、WORKBOARD、DECISIONS、KQ-010/011/012。製品工程はphone担当の `content-extension.js`（7講座176工程）に合わせ、元の642工程を短縮していない。

## 初心者・酒場・記録

- 用語14項目を追加。国内取引所の口座と銀行口座、販売所と板、成行と指値、未約定と約定、円/枚数の予約、レンディングとHLP/ステーキング、年率と期間、元本と利息、返還申請と受取、ロング/ショート、倍率と損失を分ける。全818工程で説明を呼べる。
- 元の酒場9人を維持し、セナ/スイ/ソラ/ナギ等が追加講座を相談対象にする。現行の完了工程を優先して直近2件の控えを出し、現在の目的と具体的な戻り先を話す。
- 過去の控えは、完了していない工程の教材detailsを転載しない。ゲーム更新コマンドも発行しない。
- 長老の一覧には連続して実完了した工程だけを載せる。初回講座と別条件の確認課題を混ぜない。自由選択の記録値は `journal` の対応する `STEP` 実値だけを使い、教材の初期値や `REVIEW_ACTION` を実績にしない。
- 確認課題で向きと倍率を選び直す入口を用語説明と村人ヒントで案内する。未受講の別講座を学習済みにする処理はない。
- 相談は既存dialogの内容だけを変更し、スマホのフォームや画面を再描画しない。費用・減点・時計の変更を加えていない。

## 追補 — 確定直後と次の照合の間の現在表示

親の実ブラウザー確認で、LV-01 S020の全決済後も、最新の区切りS017の「まだ閉じていない」がsticky吹き出しに残る指摘を受けた。金融パネルは決済済みで正常だが、同じ画面内の言葉が矛盾するため修正した。

- `getExtensionView` の `position.open=false` と決済履歴がある場合、S020〜S021の現在の吹き出しは「全決済は終わった」「方向・倍率・戻った額・残量ゼロを履歴で最後に照合」へ変える。
- 区切りの記録、段階数、敵HP、章の変化、XPは変更しない。最後の盾と帰港の町変化はS022の照合まで成立しない。
- 同種点検で、DX-05の取消直後S014、再注文S017、買い約定S018、売り約定S032と、LD-01の返還処理完了S019、受取S021も現在の金融状態に応じた読み取り表示へ補正した。DX-02の利用可能通知S022の後も履歴照合へ案内する。
- 長老の過去の区切りには「その時点の記録」と表示する。過去の発言を現在状態へ書き換えない。

追加した状態テストは、S020直後の訂正文、残る盾、S022までの町変化なし、state不変と、指値/貸出6境界の訂正文・盾不変を確認する。担当3ファイルの同コマンドを再実行し、**40 tests / 40 pass / 0 fail**。修正後のブラウザー再確認は親へ依頼した。この追補をもって担当範囲をfreezeし、後続レビューの指摘がなければ編集しない。
