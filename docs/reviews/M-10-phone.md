# M-10 — 入力の確認票と本人確認の三点照合

担当: phone_engineer / 2026-10-23。対象は M-01-L2 / L3。親が app.js と共通 styles.css を所有し、本担当は割当の画面 module と専用 CSS、必要なテストだけを編集した。孫エージェントなし。

## 修正

- `js/phone-funding.js` を追加。`renderFundingPanel({document,state,step})` は `{element,handlesAction:false}` を返す。FI-01〜03 の全70工程を既存の1工程1操作で進められるまま、現在の区間に合う確認票を描く。
- FI の「今回、入力した内容」は `financialScenarios['funding-japan'].phoneState.formDrafts.funding` から読む。未入力を正解の予定値で埋めない。誤った宛先・道・数量もそのまま確認票に出し、受取カード・見積との不一致を見られる。JSON復帰でも同じ実入力を読む。
- 入金、購入、出庫、交換、道替え、ガス、引継ぎを分ける。固定の金融 module の quotes は「受取カード・教材の見積書（確定前の予定）」、実 accounts は「台帳に記録された、いまの置き場所」として表示。送信前・処理中・到着・購入済み・移管済みは実台帳の状態で区別する。UIで残高を計算・更新しない。
- `js/phone-extension.js` の DX-02 確認票は S015 の表示だけでなく、同一人物の照合 S016 と提出 S017 まで表面・裏面・画面内人物の3点を保つ。`getExtensionView` の profile と、その課題の選択済み idType / idFront / idBack / selfie を読む。未選択やぼやけた状態を良好な状態に置き換えない。
- DX の独立復習 A015〜17 は復習専用 snapshot の氏名・生年月日・住所・期限・選択を使う。本編の朝日ミナトを、木立アオイの確認へ混ぜない。
- `styles/phone-extension.css` は3点確認票の名前・選択控え・画像を区別し、幅520px以下では縦に並べ、各画像の横に照合内容を置く。

金融の固定値・計算処理、state / 保存 schema、工程ID・工程数・報酬は変更していない。app.js での接続と既存の全台帳を details に畳む変更は親の所有範囲で行う。
