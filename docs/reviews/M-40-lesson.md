# M-40 用事の前に読むナレーション

実装：受注・再開後に親が表示する短い案内の読み取り情報。『なぜこの用事をするか』『何を練習するか』『いま押す操作』を分ける。新規js/lesson-guide.js、tests/lesson-guide.test.mjs、本書のみを編集した。既存工程、XP、金融台帳、保存版、未受講の学習状態は変更していない。家やスマホの描画、ナレーション窓の表示と閉じ方は親が統合する。

## API

`getLessonGuide({state,quest,step})` → title/story/practice/steps（3〜4行）/firstAction/任意のflow。全通常34依頼と副練習2件に、用事の意味と技能の説明を与える。物語は既存questBriefの依頼人と困りごとから導く。

firstActionは対象依頼の実保存工程を優先し、そのinstructionを返す。古いstepを渡しても最初の工程へ戻さない。appIdは実際の表示場所と異なる場合があるため、画面名をlesson側では付けない。親のphoneAppForStepが表示場所を案内する。

このmoduleはdispatch/storageを呼ばず、コード、入力値、clipboardの中身を読まない。ナレーションを閉じるだけではSTEP/XPが進まない。親の『練習へ』ボタンは、実スマホの対象を見せるために使い、工程を完了するボタンとして接続しない。

## コピーの案内

|依頼|コピー元のmailId|戻るアプリ|コピーする実ボタンのラベル|
|---|---|---|---|
|PR01|intro-mail|memo|合言葉をコピー|
|PO01|registration-mail|browser|このメールの練習コードをコピー|
|BK01|bank-verification|bank|このメールの練習コードをコピー|
|DX01|domestic-registration|browser|このメールの確認コードをコピー|

flowはsource/destinationのアプリIDとsourceLabel/destinationLabel/mailId/clipboardLabelを返す。コードや合言葉の実値は含めない。『今回届いたメール』を読む→その本文でコピー→元アプリへ戻る→指定欄へ貼り付ける→認証/保存/結果の順を説明し、別の用事のコピーは使わないと添える。

途中再開は残りの見通しへ切り替える。PR007/008、PO015、DX014のアプリ切替では、最初からメールを読み直す案内を出さず、元の画面→貼付→確定を示す。認証済みのDX/BKでは、成人カードを写す申込の続きへ。認証/保存後にコピー図を繰り返さず、flowを省く。完了依頼を参照した場合も、やり直す操作へ誘導しない。

## コピー以外

FI/暗号資産の送信は、受取カード、資産、送り道、数量、費用を比べ、到着明細までを見る。板取引は注文受付・予約・成立を分け、貸出は手元/貸出中・満期/受取を分ける。FXの準備では注文が既に成立したように扱わず、決済は元の建玉から閉じると説明する。選択ラボ以外を学習済みと認定しない。

通貨ペア、lot、本人確認、ネットワーク、ガス、指値/未約定、元本/利息、委任、証拠金/倍率などは、使う用事のpracticeに短い言い換えを置いた。長い用語解説は既存の説明/酒場へ任せる。
