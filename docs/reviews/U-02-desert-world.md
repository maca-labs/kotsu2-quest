# U-02 / U-03 世界地図・砂漠・教会・当たり判定

担当: world_engineer。2026-10-23。対象は親の今回のUI統合前の共有作業差分。金融・学習・保存契約は編集していない。

## 実装

- 世界地図は既存64×48、表示25×18を維持。7町・7洞窟の位置と入口IDを維持した。
- 町の周りは草原、町の間は山脈と幅3の道・峠とし、徒歩では序章→第1→第2→第3→第4→第5→第6章の順の地形を通る。章の直接選択・解禁契約は変更しない。中間の町への強制入場はない。
- 砂鳴りの砂漠は世界座標x53..59/y27..33。通常経路から外れた48,29→52,29の脇道で入る。標識52,29に「この先 砂漠・超強敵 →」を描画。`isDesert(location)` / `getTerrainLabel(location)` / `desertArea`をexport。砂は歩行可。
- CH-0限定で「はじまりの教会」を追加。扉19,15、屋外復活点19,16。`townDoors`のchurch項目のみ`chapterId:'CH-0'`。`doorAt(x,y,chapterId)`、`drawTownDoors(...,chapterId)`は章を渡さない場合に従来3軒を維持する。
- `roomTitle/roomPeople/roomStep/renderRoom`はchurch対応。神官ミル、祭壇、長椅子、中央通路を独自のピクセルで描く。`roomSpawn`12,12から神官に話しかけられ、出口12,15から戻れる。
- 店、長老の家、教会の足元をhouseとして衝突判定。噴水はx11..13/y7..8の3×2タイルに描画・判定をそろえ、`fountain`を歩行不可にした。店・家の扉への入場処理は親UIが衝突判定前に行う。
- 検証で既存CH-3のspawn12,16が水に囲まれ歩けないことを発見。港の中央x12を桟橋として通れるよう修正した。

## 確認

実行: `node --test tests/rpg-world.test.mjs tests/rooms.test.mjs tests/world.test.mjs`

18件成功、0件失敗。全14入口へのBFS到達、各入口の南側帰還、7洞窟の全床到達、山横断不可、CH2→CH3の峠を閉じた場合に前後の地域が分離されること、砂漠の全49床到達、教会の入退室・祭壇/人/椅子との衝突を確認した。全7町のspawnから全扉の手前、店の手前、南門の手前へ到達できることを確認した。キャンバスは有限の描画座標で動き、呼出元の学習進捗を変更しない。
