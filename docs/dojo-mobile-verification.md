# 第6章　向きと倍率の稽古場

## 公開版の初回プレイで迷った場所

Windows版Chromeをスマホ幅にし、小6でスマホ操作が苦手な初心者を想定したAIが、通常のセーブを読み込んだ。第6章の依頼帳で稽古場を選び、ソラから受注して、町の南門と街道を通り、洞窟の門番と戦った。倍率の内訳を開いた後も、画面には次のボタンと注文前の残高だけが見えていた。5倍と500のつながりを読むには上へ戻る必要があった。

別担当が幅320pxで再現した。倍率を選び直すと上の欄にも以前の値が残った。証拠金の誤入力の直し方が画面の外にあり、正しい全角の１００も通らなかった。決済後に手元に残る額をソラへの報告で読み返せなかった。初心者役は上へ戻って計算を確認し、全22工程を終えた。洞窟内の戦闘を2回経て、近道を使わず学者の家へ帰った。

## 今回の練習でお金が動く順番

すべて稽古場だけの架空のお金。単位はMock USDC。選んだ条件はショート・5倍、教材価格は100から105へ。手数料と資金調達料はこの自由練習では0。

|場面|取引に使う分と損益|手元で使える額|
|---|---|---:|
|注文内容を選ぶ|証拠金100 × 5倍で取引額500。1枚分の価格が100なので、5枚分の値動きを受ける|1,000|
|注文を確定|証拠金100を取引に使う|900|
|価格を105に進める|100で売る向きで始め、105で買い戻す計算。1枚分の差額5を払うので、5枚分で含み損25|900|
|全決済を確定|損失25が確定。100から25を引いた75が戻り、残りの建玉は0枚|900＋75＝975|
|町でソラに報告|ソラと決済の明細を読み返す|975|

## 修正と検査

各操作のそばに選択中の試算または確定した明細を表示する。手元の原資は注文で、含み損益は価格を進めた時に、実際の返還額は全決済で変わる。スマホの選択欄で選び直すと、上のアプリ画面と手元の明細が同時に追従する。全角の１００も入力できる。稽古が終わると、学者の家への帰り道が表示される。

スマホ幅はタッチを有効にしたWindows版Chromeで確認した。実機のソフトキーボードと実際の小学生による観察は未確認。

幅320pxの公開前確認で、ソラに会う前に広場で村長に話すと報告済みになることも見つかった。広場の村長は学者の家を案内し、ソラへの報告を保留するよう修正した。金融担当は向き2種類・倍率3種類・価格2種類の12条件で、各22工程の途中復帰と同じ操作の再送を各264回確認した。稽古場の決済は1件で、本編ラボと条件を変えた復習それぞれの残高も独立していた。

ゲーム全体の自動テストは490件すべて通過。公開された入口HTMLと今回変更したJavaScript 9ファイルは、配信後に取得してコミット52b9b05の内容と一致した。[ゲームを公開したGitHub Pagesの記録](https://github.com/maca-labs/kotsu2-quest/actions/runs/45014349538)

## 修正後の公開版をもう一周

以前の公開プレイで第6章をクリアした時のセーブを、初回と同じく設定から読み込んだ。初心者役は新しいChromeの360×780で、第6章の依頼帳からソラに会い、南門と街道を歩いて帰り帆の洞窟へ入った。門番の「帰り風のクモツバサ」を倒し、自分でショート・5倍を選び、新規注文の後に「道ふさぎコケリン」ともう一度戦った。今回は行き帰りの街道での戦闘は0回だった。[洞窟での2戦目](./dojo-verification/cave.png)

倍率を選んだ時には、入力欄と同じ画面に証拠金100・取引額500・5枚分が出た。教材価格を105に進めた後は、売る向きで始めて高く買い戻すために差額を払うこと、その時点ではまだ損失が確定していないことを読めた。[5倍を選んだ画面](./dojo-verification/fivefold.png)・[価格が上がった後](./dojo-verification/price-rise.png)

全決済の直後に、5枚分の損失25と、残り0枚、900＋75＝975を確認した。洞窟から近道を使わず戻り、学者の家でソラ本人に明細を見せた。金額を確認するために追加で上へ戻る操作は不要だった。[全決済の直後](./dojo-verification/settled.png)・[ソラに見せた明細](./dojo-verification/sora.png)

通常の書き出しから復元した記録を照合した。新たな操作は34件で、稽古の22工程は順に1回ずつ。新規注文・価格変更・全決済は各1件だった。稽古のXPは初回22工程の44と依頼達成40で合計84。ほかの31の資金台帳は開始前と一致した。

別担当の公開版タッチ確認では、320×360と320×650でも22工程すべてと徒歩帰還・本人への報告を完了した。全角１００で入力でき、誤った額を直す理由も同じ画面で読めた。広場で村長に話し、町に戻って再読み込みしても報告は残り、学者の家でソラに話すと完了した。[高さ360pxの注文画面](./dojo-verification/narrow-order.png)・[同じ画面幅での報告](./dojo-verification/narrow-report.png)
