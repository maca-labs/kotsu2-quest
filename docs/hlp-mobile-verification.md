# 第6章・HLPの預入と帰還

## 公開版で初心者役が迷った場所

小6でスマホ操作が苦手な人を想定したAIが、Chromeの360×780でプレイした。初回観察では、公開プレイの記録をゲームの通常処理で再生し、第5章の最後の選択をHLPにしたセーブを使った。ソラの本編を終えると報告と次の依頼へ案内され、追加預入の練習を見つけられなかった。ルカへの報告と古龍の試練を終えた後、依頼帳の「流動性の塔」を探し、「条件を変えて確認」から追加の練習を発見した。さらに別の新しいブラウザーで第5章を最初から最後まで遊び、実際にHLPを選び、章印を取ってゲームからJSONを書き出した。

預入前から値下がり後の金額が画面に並び、現在の金額を確かめるために上へ戻る必要があった。追加の確定画面には同じ指示が3回並び、今預けている額と引き出せる日を一緒に見られなかった。幅320pxでも誤入力の訂正文が画面外にあり、全角の「３００」と「５０」が正しい額でも拒否された。

## 画面で確かめるお金と日付

この章の金額はすべてゲーム内のMock USDC。日数も練習画面の操作で進む。

| 本編 | 預けている元本 | その時の値打ち | ラボの手元 |
| --- | ---: | ---: | ---: |
| 0日目に預入を確定 | 300 | 300 | 700 |
| 2日目、1口100から97に変化 | 300 | 291 | 700 |
| 4日目、全額の引出しを確定 | 0 | 0 | 991 |

本編の991を自分の練習財布へ出金すると、教材費1を引いた990が処理中になり、到着操作で財布に990が入る。第5章の財布900とハイリキ99は元の場所に残る。

| 追加預入の練習（1口100に固定） | 預けている額 | 手元 | 引き出せる日 |
| --- | ---: | ---: | --- |
| 0日目に300を預ける | 300 | 700 | 4日目 |
| 2日目に50を追加する | 350 | 650 | 6日目 |
| 6日目に350を引き出す | 0 | 1,000 | 引出し済み |

この教材では、口座全体の引出日を最後の預入から4日後に設定する。2日目に追加すると先に預けた300にも新しい日が適用され、最初の予定だった4日目にはまだ2日残る。条件の異なる問題を終えた後も、出金するのは本編の991。章ボスも専用の別口座を使い、100から教材費1を引いた99を受け取る。

## 自動検証・技術QA

金融担当が通常処理で本編27工程、追加練習25操作、出口26工程、章ボス5課題33操作を検算した。初回と追加のどちらも、引出日になる1ミリ秒前は拒否され、ちょうど4日で引き出せた。保存復帰23回、誤入力29回、同じ工程の再送109回と金融イベントの再送15件で不正な資金・XPの増減はなかった。旧公開版が出力した途中保存15個で、復元後の状態と次の操作が一致した。以前の画面で「300.0」を入力して預入確定で止まっていたセーブも続きから進めた。

人間の小学生による理解度や面白さ、スマホ実機のソフトキーボード、iOS Safariは未確認。
