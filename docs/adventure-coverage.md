# 操作に反応する冒険と初心者ヘルプ

> 追加講座導入前の642工程版の記録です。現行818工程の差分・実施範囲・合否は[追加対応](./extension-coverage.md)と[統合検証](./extension-verification.md)を参照してください。以下の件数・操作説明・AGENTSの有無は当時のものです。

`js/adventure.js` と `js/help.js` は、保存済みの状態から表示用の情報を作る純粋なモジュールです。既存の工程、金融イベント、XP、熟練度、受注時計、装備の報酬を変更しません。

## 途中の小敵と村人の反応

通常24クエストと追加2課題の572工程を残し、資金準備FI-01〜03の70工程を加えた29クエスト・642工程を対象とします。各クエストに異なる事件、依頼人、小敵の名前、具体的な助ける目的があります。

29クエストに107の区切りを定義しました。83は封印を解く区切り、24は手がかりを得る区切りです。最大8工程以内に次の反応があり、確定・受取などの重要な結果では短い区切りもあります。封印1つは敵の守り20に対応し、ただ読む・メールを見つけるだけの手がかりでは守りを減らしません。

例：会員登録は、練習入力→メール発見→認証で反応が変わります。交換は申請だけで敵を倒さず、受取履歴まで必要です。振込は受取人・金額・承認・受取の各区切りで橋がつながります。FXでは損失があっても正しく全決済し、記録を残せば進みます。円からの資金準備では、購入・財布への出庫・種類交換・道替え・ガス準備を別の反応として扱います。

HPは、そのクエストの先頭から連続して完了した工程IDだけで計算します。未完了の途中工程を飛ばして末尾のIDを置いても進みません。XP・利益・倍率の大きさはHPに影響しません。入力を直してもHPが回復する罰はありません。

`getAdventure(state, quest, step)` は `enemy`、`stages`、`currentStage`、`latestReaction`、`nextGoal`、`chapterChanges`、`clues` を返します。`getChapterChanges` は実際に成立した区切りの町への反応を集めます。読んでいないラボの町変化や熟練度を作りません。

出口は経路別の完了記録を使います。単独の運用見送りを先に終え、その後に入金の旅を進めた場合の `HY-EXIT:journey-main` も、先に終えた出口から工程を借りません。過去に実際に起きた町の変化は、別の経路を選び直しても残ります。

## 酒場で前の控えを見直す

`getTavernAdvice` はミナ、ハル、スイ、ナギ、コハク、ルカ、ソラ、セナ、長老オリベの9人を返します。各人の得意分野と、現在の依頼で前に入力・確認したことを対応させます。

`recallStepIds` は存在する実完了IDだけです。未見の場面を「前に見た」と扱わず、初めてなら前提説明を返します。手帳へ保存したFXの条件は、完了工程とは別の保存済みカードとして区別します。控えは表示用の証拠で、金融操作を再実行する入口ではありません。相談は無料・減点なしで、状態を変更しません。

長老の `getAdventureChronicle(state)` は、実際に完了した全工程を依頼ごとの記録に整理します。工程の操作、意味、つまずきやすい所、成立した結果、突破した区切りを読み返せます。受注しただけの依頼や未見の未来の工程は出しません。途中の依頼は「途中まで」と明記し、出口は選んだ経路・単独の見送り・後から進めた入金の旅を別の記録として扱います。記録庫から過去の金融操作を実行しません。

村人の便りは、その区切りで起きた事実として書いています。時間送りで到着した後も残る便りが「まだ移動中」「今は待機中」と現況を誤って断定しないようにしています。

## 「これは何？」「なぜ？」「どうすれば？」

`getHelpTopics(step, quest)` はクエスト、現在の操作、項目、資金準備の `helpKeys` から説明を選びます。全642工程に、汎用の説明だけで終わらない文脈別の入口があります。

ことばの本には75項目を収録しました。MCHI、円からの支度、USDC、ETH、Arbitrum、ウォレット、ネットワーク、HyperCore、HyperEVM、種類交換、道替え、ガス、FXのlot・Bid/Ask、本人確認、ポイント条件、売上と未入金などです。資金準備の15用語も同じ説明形式へ統合しています。

各項目は短い説明、理由、今すること、例、必要な場合の図用ラベルを持ちます。ヘルプは現在工程の正解値を自動で差し込みません。`humanFieldLabel` と `displayPracticeValue` は、`employee`、`ordinary` などの内部値を日本語へ置き換えます。未知の内部名もそのまま画面へ出しません。

## 確認した範囲

`tests/adventure.test.mjs` と `tests/help.test.mjs` では、全クエストの区切りと反応間隔、読むだけで攻撃しないこと、受取前の未撃破、連続した完了証拠、HPの単調性、エラー時の不変、未受講ラボ、経路別出口、酒場の実完了参照、全工程の文脈説明、用語の区別、内部値の日本語化、入力の不変性を検証します。

これは表示データと状態の結びつきの確認です。面白さ、また遊びたくなる気持ち、小学6年生の理解を検証したという意味ではありません。実画面での読みやすさ、会話と操作のタイミング、対象者による意味の説明・自発的な再訪は別に確かめる必要があります。
