# こつこつクエスト — 小さな一歩の冒険譚

**[公開版を遊ぶ](https://maca-labs.github.io/kotsu2-quest/)** — インストール不要。スマートフォンやパソコンのブラウザーで開けます。

町の人の依頼を受け、ゲーム内のスマホで入力・照合・確定・受取を一つずつ練習する、日本語のドット絵RPGです。HTML・CSS・Vanilla JavaScript ES Modulesだけで動きます。ビルド、CDN、アカウント登録、外部APIは不要です。

人物・サービス・口座・カード・価格・資金は、すべて教材の架空データです。実際の買い物、銀行接続、ウォレット接続、カメラ、NFC、秘密情報の入力は行いません。USDC・ETH・Arbitrum・HyperCore等の名称を説明に使いますが、実サービスやネットワークには接続しません。ゲーム内の利益や特典は、現実の利益や特典を約束するものではありません。

## ローカルで起動する

Node.jsが利用できる環境で、このREADMEがあるフォルダーへ移動します。開発・自動テストはNode.js 24で確認しています。依存パッケージのインストールは不要です。

```powershell
git clone https://github.com/maca-labs/kotsu2-quest.git
cd kotsu2-quest
node tools/serve.mjs
```

[ローカルのゲームを開く](http://127.0.0.1:8765/) にアクセスします。停止はターミナルで `Ctrl+C` です。`npm run serve` でも同じ静的サーバーを起動できます。

```powershell
npm test
```

自動テストだけを実行します。`node --test tests/*.test.mjs` でも実行できます。`index.html` を直接ダブルクリックする `file://` 起動では、ES Modulesや保存が動かない場合があります。必ず静的HTTPサーバーを使ってください。

リポジトリ名付きのサブパスをローカルで確認する場合は、別のターミナルで親フォルダーを配信します。

```powershell
node tools/serve.mjs .. 8766
```

[サブパスでゲームを開く](http://127.0.0.1:8766/kotsu2-quest/) で、ES Modules・CSS・素材と再読込みを確認できます。このURLとポート8765は配信元が異なるため、セーブも別になります。

## 遊び方と章の選択

1. 最初のミッションから序章へ出発するか、「章を選ぶ」から気になる町を選びます。序章を含む全章を最初から選べます。
2. 上部の短い「次の一歩」に従い、家へ入って住人の困りごとを聞き、依頼を受けます。南門から世界地図へ出て、金色の旗が付いた洞窟を目指します。洞窟の魔物に近づいて話し、門番と戦います。
3. 門番を倒したら「案内役のひとこと」で目的と練習の順番を読みます。序章・モール登録・国内取引所登録では、字幕付きの実画面のお手本動画も見られます。その後、自分で欄を押す・練習値を入れる・確認する・確定する・結果を見る、を一つずつ進めます。
4. 正しい入力や受取の区切りで小敵の守りがほどけ、依頼人の返事と町の様子が変わります。
5. 章の依頼と章ボスの確認課題を終えると、章印と装備を受け取れます。別の章へ移っても、途中の入力・依頼・受注時刻は残ります。

章選択に前の章の章印、序章の完了、コード入力は必要ありません。章の中では、その依頼に必要な手順を順番に進めます。第6章は選べる4ラボと運用見送りを用意し、選んでいない内容を自動で学習済みにはしません。

従来配布した次のコードも、設定の合言葉メニューで引き続き使えます。現在の版では任意の互換入口です。

|編|コード|範囲|
|---|---|---|
|序章|不要|旅立ちの村|
|ポイ活編|`POINT-START`|第1〜4章|
|クリプト編|`CRYPTO-START`|第5〜6章|

コードは全角英数字を正規化し、前後の空白を除いて照合します。英小文字でも入力できます。コードは厳密なアクセス認証ではありません。再入力しても資金・XP・装備は増えません。

画面の十字キーは押し続けて歩けます。押したまま指をずらして向きを変え、中央の「話す」で近くの人と会話します。矢印キー・WASD・Enterも使えます。家の扉まで歩くか扉を押すと室内へ入り、下の光る扉から町へ戻ります。依頼人の家・酒場・長老の家には、ボタンからも入れます。

スマホでは「いま、すること」と、実際に押す対象の矢印・枠を見て操作します。「矢印の場所へ」で対象まで移動できます。メールのコピー元→戻るアプリ→貼り付ける欄も示します。お手本は序章を実際に操作した画面を工程ごとに止めた約30秒の字幕動画です。現行案件のコードは自分のメールからコピーします。説明・動画・矢印を見ただけでは工程やXPは進みません。

メニューの「町の人・町からの便り」と「依頼帳」からも同じ会話と練習へ進めます。スマホのホーム、アプリ切替、ブラウザーのタブ切替、町へ戻る操作は、それぞれ別の入口です。メールや控えを見直してから、途中の入力へ戻れます。

町・室内・野外では、地図と十字キーを最初の画面へ置いています。上部は現在地・体力（HP）・次の一歩だけ。右上の「メニュー」で依頼帳・装備・相談・宿・近道・章選択・設定を開きます。Escで閉じられ、開閉だけで工程やXPは進みません。

## 世界地図・洞窟・戦闘・武具店

世界地図は64×48マス、画面は主人公を追いかけます。7つの町と7つの洞窟を歩いて訪問できます。町は各章の地形・目印・住人が異なり、家・酒場・長老の家・武器防具店へ入れます。長い歩行が難しいときは、右上の「メニュー」→「歩く代わりの近道」から行き先へ移動できます。章選択も引き続き自由です。

山脈と峠の道が序章〜第6章を順につなぎます。徒歩の道順と、好きな章から出発する章選択は別です。噴水・水・建物・山には当たり判定があり、扉や道を通って移動します。

町を出た街道でも、案件を受ける前から敵が現れます。初回は成功歩行4歩、以後は20歩の間隔で、壁押しは数えません。依頼の入口と、確認・受取などの区切りにも旅の敵が現れます。戦闘では敵の予告を読み、「こうげき」「まもる」「わざ・強打（1戦1回）」「にげる」を選びます。逃走は学習を消さず、同じ敵を次の入力ごとに押し戻しません。道中や洞窟で再挑戦できます。野道や砂漠で負けると始まりの村の教会で全回復し、案件・装備・コイン・XP・練習資金を保って再開します。洞窟の案件戦で負けたときは従来どおり同じ町の宿へ戻れます。

港の北へ続く道の東に、危険な砂漠の脇道があります。砂地を2歩進むと「砂暁のガルザドン」が現れます。初期装備ではほぼ一撃で倒されますが、「にげる」は必ず成功し、逃走後8歩は再遭遇しません。倒れた場合も教会で復活できます。原作の固有モンスターや素材は使用していません。

初めて倒した敵からのみ冒険コインを受け取ります。コインは武器・防具の購入専用で、教材の円・ポイント・暗号資産と交換しません。銅剣24/旅服20/鉄剣60/よろい50コインを、価格確認→購入→装備で身につけます。武器はダメージ、防具は受けるダメージに効き、主人公の見た目も変わります。手帳の最大HP、盾の防御、大剣の攻撃など、章の報酬装備にも旅戦での効果があります。杖や別の武具へ持ち替えると実際の能力も変わります。

旅戦は固定の学習XPを追加しません。既存の章ボスの確認課題は全部残り、装備で飛ばせません。旧保存の完了案件や途中案件は、入口の門番戦のために学習を巻き戻しません。戦闘途中のHP・敵HP・ターン・強打の使用、コイン・購入・装備はJSONと自動保存から復帰できます。

## 酒場・説明・過去の控え

作業画面の「これは何？」「なぜ確認する？」「酒場で聞く」から、いまの操作に合う短い説明、理由、例、図を開けます。町の酒場と「ことばの本」からも同じ説明へ進めます。USDC・ETH・ネットワーク・ガス・lotなどを、知っている前提で進める必要はありません。

酒場の人は、いまの依頼に関係する入力や確認を振り返ります。長老オリベには、過去に実際に終えた案件の記録・説明・つまずきの整理を見せてもらえます。未受講の案件を「前に体験した」と扱いません。控えの閲覧や相談は無料で、資金移動や報酬の再実行はしません。

通常34クエストと追加2課題には、142の反応の区切りがあります。そのうち106は小敵の封印を解く区切り、36は手がかりを得る区切りです。次の反応まで最大8工程とし、購入・確定・到着などでは短い区切りもあります。ただ読んだだけでは守りを減らさず、利益額や倍率でも攻撃力を増やしません。詳しくは[冒険と初心者ヘルプの対応](./docs/adventure-coverage.md)を参照してください。

ガイド付きの入力では、「カードの値を入力」は欄を埋めるだけです。内容を見てから別の送信ボタンを押すと、その入力工程を進めます。欄を押す工程、確認画面へ進む工程、注文・送金等を確定する工程、結果を照合する工程は別です。条件を変えた確認課題では、正解候補の自動入力を表示しません。

|LV-01|22|ロング/ショートと1/2/5倍、価格95/105の選択、建玉、損益、全決済、残量0|

第5章の町でDX-01→DX-02を始め、完了後に「円の入金から、ハイリキへの旅を続ける」でFIへつなげられます。FIは申込済み設定の「こみち交換所」の教材窓口を使います。口座づくり・売買練習と送金の旅の財布は別です。旧セーブや送金から学びたい人は、従来のFIからも始められます。申込や本人確認を自動で学習済みにはしません。

DX-03〜05は本人確認後の寄り道、LD/LVは第6章の独立した追加練習です。元の4ラボ＋見送りの選択、章ボス、装備の獲得条件を増やしません。板の売買は数量のある教材注文一覧で見比べます。別窓口を見学中は注文を受け付けず、元の画面へ戻って続けます。

新7講座には本編と別の確認用コピーがあります。申込者を変える、数量を10枚から5枚へ変える、貸出元本を100から200へ変える等の条件を使います。LVは自由に反復でき、方向・倍率・値動きが本編とすべて同じ場合は「同じ条件の復習」とし、別条件の技能証拠を増やしません。いずれも初回XPや本編残高を増やしません。

現在の建玉と、閉じた取引の履歴は別枠です。村人の吹き出しも決済後・取消後・受取後の実際の状態を伝え、最後の照合まで封印は残ります。長老は実際に選んだ向きと倍率を読み返せます。[追加講座の工程・数理・確認結果](./docs/extension-coverage.md)に契約と検算をまとめています。

## 第5章：国内の円から入金できる資産を準備する

FI-01〜FI-03の70工程で、円の入金、国内の架空サービスで購入・出庫できる教材コインの選択、自分の財布への出庫、必要な交換・道替え、ガス準備を分けて操作します。実在する国内サービス共通の経路ではありません。

|段階|この教材の架空値と現在地|
|---|---|
|銀行→こみち交換所|銀行200,000円から120,000円を入金。銀行に80,000円が残る|
|教材コインを購入|MCHI104枚を104,000円で購入。交換所に16,000円が残る|
|自分の財布へ出庫|出庫104枚から教材費1枚を引き、みち道のMCHI103枚を受け取る|
|資産の種類を交換|MCHI103枚を、みち道の1,030 Mock USDCへ交換|
|ネットワークを道替え|教材費20を引き、Arbitrumの1,010 Mock USDCを受け取る|
|ガス用の資産を準備|10 Mock USDCで0.001 Mock ETHを用意。残るUSDCは1,000|
|既存の旅へ引き継ぐ|同じ1,000 Mock USDCと0.001 Mock ETHの記録をCR-01以降へつなぐ|

引継ぎは資金の追加配布ではありません。準備台帳の財布を0にし、既存の`journey`の開始資金への参照を残します。既存の旅へ1,000を加算しません。その先のCR-03では100 Mock USDCを送り、教材費1を引いた99の到着と、別に使ったガス0.0001 Mock ETHを照合します。

すでに入金や出金を進めた旧セーブでは、追加のFIは独立した準備の復習です。主シナリオの残高や履歴を巻き戻したり、未受講のFIを自動で達成済みにしたりしません。各ラボの独立した元手も変更しません。[資金準備の工程・数理・引継ぎ](./docs/funding-coverage.md)に詳細を記載しています。

MCHI、みち道、こみち交換所、道案内交換所は架空です。交換・道替えの処理費を含む教材見積書を使っており、ガス未準備の実ウォレットで同じ順番を実行できるという意味ではありません。現実の国内サービスの取扱銘柄、出庫先制限、現在の交換・ブリッジ経路、料金や所要時間は保証しません。

## XP・熟練度・24時間チャレンジ

|初回の達成|XP|
|---|---:|
|登録された1工程|2|
|通常クエスト|40|
|章ボス|50|
|隠しボス|100|
|対象NPCの役立つ初会話|3|
|任意の時限チャレンジ|10|

追加課題には初回工程XPだけを付け、通常クエスト報酬・時限報酬・章印を増やしません。同じ工程、会話、報酬、通知、取引を繰り返しても、初回報酬は重複しません。レベルは `1 + floor(totalXp / 100)` です。利益額、lot数、取引回数によるXP倍率はありません。

熟練度は分野ごとの5技能について、ガイド付きの証拠と、条件の違う確認課題の証拠を分けます。各技能は10点＋10点、分野合計100点です。ヒントで減点しません。装備は見た目と便利な入口を変え、必要な照合や確認は省略しません。

受注時に「24時間でやってみる」か「自分のペース」を選べます。設定の時限ボーナス、時間表示、受注からの時間数を変更できます。初期値は24時間です。設定変更はこれから受ける依頼に適用し、受注済みの期限を動かしません。序章と追加課題は時限対象外です。

起算は初回受注を確定した端末時刻です。完了時刻が期限と同時なら対象、1ミリ秒でも後なら通常クリアになります。期限後も基本XP、熟練度、装備、章印を得られます。途中で自分のペースへ切り替えることもできます。

審査、配送、承認、ロック待ちは、教材の時間送りで体験します。教材内を7日進めても、現実の期限は7日進みません。実際の申込・入金・取引を急がせる期限ではありません。端末時計が最後の観測から5分以上戻った場合は、時限加点を保留して基本報酬で続けます。

## 保存・JSON書出し／読込み

保存キーは `kotsukotsuQuest.save.v3`、`schemaVersion` は `3`、`contentVersion` は `kotsukotsu-rpg-3` です。共通の冒険、金融シナリオ、工程、メール、入力、時刻を一つのJSONとしてlocalStorageへ保存します。ブラウザー・プロファイル・配信元が変わると保存場所も変わるため、移す前に設定・保存からJSONを書き出してください。

読込みは2 MiB以下、操作記録等は10,000件以下を受け付け、登録ID、数値、順序、残高、報酬、装備等を検証します。金融残高やXPは確定イベントから再構成し、JSONに書かれた合計だけを信用しません。検証に失敗したときは元の記録を維持します。

localStorageを利用できない場合は、その画面内で続けてJSON退避を案内します。破損した記録は無断で上書きせず、元データを書き出せます。新規開始で消去する前には影響を表示します。旧版の `trainingHub.save.v1`、`pointquest.save.v1` / `v2`、`hyperliquidRehearsal:v1` は削除・自動移行しません。

同じ配信元の別タブと同時に編集しないよう、Web Locksが使える場合はロックを使い、利用できない場合は編集権の記録と更新番号で競合を検出します。古いタブは編集を停止し、再読込みを案内します。別端末との自動同期や、サーバーによる時刻証明はありません。
